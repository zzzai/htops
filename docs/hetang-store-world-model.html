一句话定义

门店世界模型 = 经营现实的数字化镜像 + 统一语义层 + 可执行 AI + 反馈学习机制。 它的价值不是“会聊天”，而是“能让门店经营持续变得更准确、更快、更可控”。

语义中枢

这里不是“模型替代数据”，而是“模型约束数据”：question family、capability graph、metric contract、 answerability、data coverage、policy、safe execution 共同构成可控回答链路。

question family 把人话归到稳定的问题族，而不是逐句做正则匹配。
capability graph 每个问题族映射到可用能力、可见指标和可执行动作。
answerability 先判断能不能答，再决定怎么答，不能答就明确拒答或追问。
coverage gate 数据缺口、口径缺口、权限缺口，都必须在回答前暴露出来。
  • 语义中枢是可持续扩展的事实真源，不是另一个“黑盒知识库”。
  • 所有输出都要落到审计和质量回流，形成可解释的学习闭环。

  • 多模态用于巡店图、票据、语音、视频理解，补足结构化数据盲区。

数据层

数据层不是“把所有东西都塞进一个库”，而是按数据性质分层存放。结构化事实走交易库和分析库，规则与知识走文档和向量库，多模态信号走对象存储和索引，审计与反馈单独留痕。

外部环境与外部数据

门店经营不是封闭系统。好经营往往是店内能力与外部环境共同作用的结果：天气影响出行，节假日改变消费节奏，商圈人流决定自然客源，竞品动作影响价格敏感度，平台口碑影响新客转化。 所以外部数据要作为“解释变量”进入世界模型，而不是只在分析失败后才人工猜测。

经营环境变量

天气与气候

雨雪 / 温度 / 湿度 / 极端天气

天气直接影响顾客出行意愿、预约迟到率、爽约率和项目偏好。

解释重点：为什么同样排班下客流突然下降，或者某类项目占比突然变化。
  • 雨雪、高温、低温会压低自然到店和临时客。
  • 湿冷、换季可能提升养生、热疗、肩颈类项目需求。

节假日与日历

周末 / 法定假 / 发薪日 / 开学季 / 月末

时间环境决定消费窗口、活动节奏和门店高峰时段。

解释重点：为什么本周环比变化大，是否只是日历结构不同。
  • 节假日提升家庭客、休闲客，但也可能带来员工排班压力。
  • 发薪日、月初、月末会改变充值与大额消费意愿。

商圈与交通

人流 / 停车 / 地铁 / 写字楼 / 社区 / 商场

门店不是独立点位，而是商圈流量、交通便利性和周边业态的结果。

解释重点：客流下降到底是门店服务问题，还是商圈流量本身变弱。
  • 地铁施工、停车变化、商场活动会改变到店便利性。
  • 社区型、办公型、商场型门店的高峰窗口完全不同。

竞品与价格

新店开业 / 促销 / 团购 / 评价 / 套餐

竞品不是背景噪音，而是门店新客转化、复购稳定和价格敏感度的重要变量。

解释重点：为什么新客转化下降、团购客回头率下降或折扣压力变大。
  • 附近竞品开业和低价团购会影响新客试单。
  • 竞品评价上升可能转移点位附近的自然搜索流量。

平台口碑与舆情

美团 / 抖音 / 小红书 / 大众点评 / 企微反馈

门店在线口碑会影响新客信任、活动点击、团购转化和投诉风险。

解释重点：客流没降但新客少，是不是线上曝光或评分出了问题。
  • 评分、评论关键词、差评主题要和投诉、技师、项目数据联动。
  • 爆款内容和负面内容都会改变短期自然客流。

区域事件与监管

演出 / 会展 / 考试 / 社区活动 / 检查 / 政策

区域事件会制造短期流量波峰，监管和政策会改变营业边界与经营成本。

解释重点：临时高峰是否应加排人手，临时低谷是否应避免误判为经营下滑。
  • 会展、演出、赛事会影响小时级客流和排班。
  • 检查、施工、政策变化会影响营业时间、宣传和合规风险。

业务侧

门店的业务不是单点指标，而是一条连续链路：获客、到店、服务、加钟、副项、充值、复购、唤回、转介绍、风控。 AI 的价值是把每一段链路上的信号识别出来，并给出能执行的动作。

1

到店

3

服务

项目执行、技师安排、房间占用、满意度、时长。

4

5

6

唤回 / 复购

沉睡会员、高余额客户、团购一次性客户的回访。

7

转介绍 / 风控

口碑传播、投诉处理、反结异常、折扣失控、人员风险。

老板

看营收、充值、复购、流失、门店排名和异常风险。希望系统直接告诉他“哪家店出了什么问题”。

店长

看排班、空闲、点钟、加钟、投诉、交接和现场效率。希望系统告诉他“今天该先做什么”。

运营

看新客、券核销、唤回名单、话术和活动效果。希望系统告诉他“这批人该怎么触达”。

技师

看点钟率、评价、提成、复购贡献和成长路径。希望系统帮他理解“怎样提升自己的产能”。

财务

看实收、退款、反结、对账和口径一致性。希望系统能把“钱是怎么来的”讲清楚。

AI能力

价值飞轮

真正可持续付费的不是“一个会问答的模型”，而是一个不断提升门店经营结果的系统。 它能持续影响营收、复购、储值、点钟、排班和风控，才会被继续使用。

可持续付费逻辑
1

看见问题

把问题、异常和主动洞察统一到一个入口。

2

解释原因

用数据、口径和业务逻辑解释变化。

3

提出动作

把洞察变成名单、话术、任务和提醒。

4

执行反馈

记录执行结果，确认是否真的改善。

5

学习进化

更新 contract、模板、能力图谱和阈值。

系统真正卖的是什么

不是单次回答，也不是单次报表，而是“持续让门店变得更好”的能力。只要它持续帮助门店提升营业额、复购、储值、点钟率、加钟率、客流质量和风控能力，它就有持续付费价值。

营收提升 复购提升 流失下降 人效提升 风险下降
门店世界模型的核心，不是把经营数据“做成知识库”，而是把现实门店抽象成一个可观测、可解释、可执行、可学习的系统。 数据层负责事实，语义层负责口径，AI 层负责理解和生成，业务侧负责动作，审计和反馈负责进化。
